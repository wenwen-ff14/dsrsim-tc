# dsrsim-tc｜絕龍詩模擬器

![dsrsim-tc 圖示](images/dsrsim-tc.png)

繁中版 FF14 絕龍詩戰爭練習外掛，提供 P2～P7 機制與七名模擬隊友。
參考並衍生自 **AnoMech**，由 wenwen-ff14 維護。

## 使用網址安裝

需先使用支援 Dalamud 插件的繁中版啟動器進入遊戲。

1. 開啟 Dalamud 設定，找到「自訂插件庫／Custom Plugin Repositories」。
2. 新增以下網址，啟用並儲存設定：

```text
https://raw.githubusercontent.com/wenwen-ff14/test/main/pluginmaster.json
```

3. 開啟插件安裝器，搜尋 **dsrsim-tc**。
4. 安裝「dsrsim-tc｜絕龍詩模擬器」。日後可直接透過插件安裝器更新。

## 開始練習

1. 進入**旅館房間**，輸入 `/dsrsim` 或 `/dsrsim-tc`。
2. 選擇階段、職責及機制選項，按「開始」。
3. 練習時可收合視窗，也可開啟無敵練習、站位提示與戰術圖。
4. 要重來請按「重置」；結束時按「離開模擬」返回旅館。

背景音樂可在關卡設定中開關，音量使用遊戲的 BGM 設定。
若曾安裝本專案早期的「絕龍詩模擬器」（名稱為 AnoMech），請先停用舊版再使用 dsrsim-tc。
